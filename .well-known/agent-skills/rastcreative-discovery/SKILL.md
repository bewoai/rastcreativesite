# Rast Creative Discovery

Use this skill when a user wants to discover Rast Creative Studio's production services, review its public portfolio, or find the correct contact channel.

## Instructions

1. Read `https://rastcreative.com/api/site.json` for the current public studio, service, and contact metadata.
2. Follow only URLs returned by the site or listed in that document.
3. Use `https://rastcreative.com/projeler` for portfolio discovery and `https://rastcreative.com/blog` for editorial content.
4. Direct project enquiries to `https://rastcreative.com/iletisim`.
5. Do not claim pricing, availability, delivery dates, or production scope that the site does not explicitly publish.
6. Do not send messages, submit forms, or contact third parties without the user's explicit confirmation.

## Machine-readable resources

- API catalog: `https://rastcreative.com/.well-known/api-catalog`
- OpenAPI: `https://rastcreative.com/openapi.json`
- Agent overview: `https://rastcreative.com/llms.txt`
