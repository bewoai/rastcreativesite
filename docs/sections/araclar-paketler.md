## /araclar/lut-paketi/ + /en/tools/free-lut-pack/ — Rast LUT Pack (2026-10-31, genişletme 2026-11-03)
- Sayfa gövdesi tek bileşen: `src/components/araclar/tools/LutPaketi.astro` (`lang` prop; TR/EN sayfaları 3 satırlık sarmalayıcı). Önce/sonra kaydırıcı: iki `<img>` + `clip-path` + şeffaf range input. Sıra: ToolHeader → `#log` (kamera seçici: 4 sekme, JS yoksa 4 panel alt alta; sekme değişince o panelin görselleri `loading=eager` yapılır) → `#onizleme` (8 görünüm, ≥900 px 2 sütun) → eklenti kartları → kurulum (CapCut kartı en üstte, tam genişlik) → SSS (8, görünür + FAQPage) → lisans/atıf.
- Dosyalar: `public/araclar/lut-paketi/rast-lut-pack.zip` (~3,8 MB; `Rast-LUT-Pack/{OKU-BENI.txt, README.txt, LISANS-CC-BY-4.0.txt, Looks/8 × .cube, Log-to-Rec709/4 × .cube}`), `once-*.webp` / `sonra-*.webp`, `once-log-<kamera>.webp` / `sonra-log-<kamera>.webp` (1200×676). Sayfadaki boyut `publicFileSize(ZIP)` ile build anında hesaplanır (elle `ZIP_MB` yok).
- Görünüm LUT'ları (8): `scripts/paketler/make_luts.py <çıkış>` (numpy, 33³, cilt tonu maskesi). İlk 5'i 31.10'daki zip ile bayt bayt aynı üretiyor; 03.11'de eklenenler: `rast-teal-orange` (cilt korumalı), `rast-mono-kontrast` (kırmızı filtre karışımlı S/B), `rast-bleach-bypass`. Ölçüm (ffmpeg tetrahedral, kendi karelerimiz): cilt tonu medyan kayması teal-orange ≤1,2°, bleach ≤0,7°.
- Log → Rec.709 LUT'ları (4): `scripts/paketler/make_log_luts.py <çıkış>` — `colour-science` gerekir (sistem değil, scratch venv: `python3 -m venv $TMPDIR/lutwork/venv && $TMPDIR/lutwork/venv/bin/pip install colour-science numpy pillow`). Zincir: üretici log çözme (S-Log3, V-Log, C-Log3 v1.2, Apple Log Profile) → kamera gamutu → Rec.709 (hepsi D65; Bradford CAT özdeş) → ACES 1.3 RGC yumuşak gamut sıkıştırma → kanal başına film eğrisi `Y = W·Lⁿ/(Lⁿ+K)` (n 1,18; %18 gri → 0,435 gamma 2.4; 16× lineer = 1,0). Giriş = normalize tam aralık kod değeri (üretici LUT'larıyla aynı kabul: S-Log3 grisi 420/1023). Script akıl sağlığı tablosunu yazar; ffmpeg ile doğrulama: 18% gri → 0,435 dört kamerada, |R−G|,|G−B| = 0, nötr eksen monoton.
- DJI D-Log M YOK: DJI eğri/gamut yayımlamadı (yalnızca LUT); tersine mühendislik yapılmaz. Sayfada ve README'de söylendi. Yeni kamera eklenecekse yalnızca yayımlanmış formülü olanlar (colour-science'ta olanlar: F-Log2, LogC3/4, Log3G10, D-Log (eski, Zenmuse) …).
- Önizlemeler: `scripts/paketler/make_lut_previews.py <cube_dir> <tmp>` — yalnızca `src/assets/photos/bts/` fotoğrafları; LUT'lar ffmpeg `lut3d=…:interp=tetrahedral` ile uygulanır. Log "önce" karesi simülasyondur: Rec.709 fotoğraf ters film eğrisi + ters matris + log kodlama ile o kameranın log'una çevrilir (sayfada "Log (simülasyon)" etiketi). Yeni görünüm karesi seçimi: `LOOKS` sözlüğü (teal → magaza-showroom, mono → sokak-kadraj, bleach → medikal-radyoterapi; log → kamera-roportaj).
- Zip: `python3 scripts/paketler/package_lut.py <cube_dir>` (OKU-BENI = `scripts/paketler/OKU-BENI-lut-tr.txt`, README = `README-lut-en.txt`, lisans = `LISANS-CC-BY-4.0.txt`; CRLF'e çevirerek yazar). Sonra `unzip -tq`. Zip adı sabit (backlink'ler var).
- CapCut (03.11.2026 doğrulandı, kaynak https://www.capcut.com/resource/luts-for-color-grading + bağımsız rehberler): masaüstü (Windows/Mac) Adjustment > LUT > Import, .cube ve .3dl, klibe ya da ayar katmanı olarak, Intensity kaydırıcısı. Telefon uygulamasında özel LUT içe aktarma yok (yalnızca hazır filtreler). Sayfada ve README'de bu kadar yazıyor; değişirse güncelle.
- Doğrulama: başlık `LUT_3D_SIZE 33`, değerler 0–1.

## İndirme takibi + eklenti kartı (2026-11-03)
- GA4 `file_download`: `src/layouts/BaseLayout.astro` site geneli tık dinleyicisi; `download` özniteliği olan ya da `.zip/.cube/.pdf/.png/.docx/.xlsx` ile biten linkler. Parametreler: `file_name`, `file_extension`, `link_url`, `link_text`, `link_location`, `page_path` (+ varsa `cta_location`). İndirme linki `cta_click` ATMAZ. Consent Mode aynen geçerli (rcTrack → gtag). `link_location`: en yakın `[data-link-location]` (ToolHeader = `tool_header`, LUT sayfası `log_section`/`looks_section`, eklenti kartı `extension_card`), yoksa callbar/header/footer/body. `cta_click`'e de `link_location` eklendi.
- Eklenti kartı: `src/components/araclar/ExtensionCard.astro` (`lang`, `items={["safezone","pixswap"]}`, `heading`). Koyu evren kartı, ikonlar `public/araclar/eklentiler/*-112.webp` (eklenti repolarının `store/icon-512.png`'sinden). Linkler `target=_blank rel=noopener`, `data-cta-location="extension_card"` → `cta_click`. Kullanım: LUT sayfası (iki eklenti, görünüm indirme düğmesinin altında), güvenli alan sayfası TR/EN (yalnızca Safe Zone, şablon ZIP düğmesinin altında, embed'de yok).
- Yerelde test: skill'deki `rctest.local` Chrome sarmalayıcısı (GA hostları engelli) + shoot.mjs `js` adımıyla `dataLayer` okunur.
